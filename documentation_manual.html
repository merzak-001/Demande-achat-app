Présentation Générale & Matrice des Droits (RBAC)
Aperçu Général

La plateforme Demande d'Achat automatise le processus d'acquisition d'équipements et fournitures. Elle assure la traçabilité complète des demandes d'achat depuis la saisie initiale par l'émetteur jusqu'à la validation hiérarchique N1, l'autorisation de direction N2, l'émission du Bon de Commande (BC) et le pointage des livraisons.

Principales Fonctionnalités
  • Création de demandes multi-articles avec quantité et prix unitaire estimé.
  • Attachement de pièces jointes (offres de prix, devis PDF/Images).
  • Circuit séquentiel : Manager Direct (N1) ➔ Direction Spécifique (N2).
  • Délégation de pouvoir temporaire via le modal Intérim (InterimModal.jsx).
  • Traitement Acheteur : Fournisseur retenu, N° BC et pointage des quantités livrées.
  • Génération et impression de la fiche réglementaire 4 signatures (PrintableRequest.jsx).
Technologies & Frameworks
  • Frontend: React 18, Vite, Tailwind CSS, Lucide Icons, i18next (FR/EN/AR).
  • Backend API: Express.js avec authentification JWT et cryptage bcryptjs.
  • Base de Données: Microsoft SQL Server (Connecteur mssql / msnodesqlv8).
  • Administration: Panneau de configuration utilisateurs, départements & modal SQL.

Guide Demandeur : Formulaire de Saisie & Modal
Portail Demandeur
1. Saisie des Articles & Urgence

L'émetteur indique l'intitulé du besoin, sélectionne le département et choisit la priorité (Normale ou Urgente). Les lignes d'articles précisent le code article, la désignation, la quantité et le prix unitaire estimé.

2. Pièces Jointes & Fichiers Devis

Chaque réquisition permet le téléchargement de documents justificatifs (offres de prix fournisseurs, fiches techniques PDF ou images), qui restent consultables par tous les valideurs du circuit.

3
Guide Valideurs (N1/N2) & Gestion des Intérims
Circuit d'Approbation
Circuit à 2 Niveaux (N1 & N2)

Le niveau N1 exige l'approbation du manager hiérarchique direct. Le niveau N2 consulte le code direction assigné (ex: Direction Production DP, Direction Générale DG) pour l'arbitrage budgétaire final.

Modal d'Intérim (InterimModal.jsx)

Chaque responsable peut désigner un collègue intérimaire sur une plage de dates précises. Les validations effectuées sous intérim sont enregistrées en base avec la traçabilité intégrale du nom du délégué.

4
Guide Acheteur & Fiche d'Impression Officielle
Traitement Achats
1. Portail Acheteur & Affectation

L'acheteur consulte la file d'attente (En Attente), s'affecte la demande, renseigne le fournisseur retenu, saisit la référence du Bon de Commande (PO) et pointe les quantités livrées au fur et à mesure des réceptions.

2. Impression Fiche Officielle

Accessible à tout moment via le bouton imprimer ou la route /print/:id. Génère un document au format paysage/portrait calibré pour une impression papier parfaite avec les 4 grilles de signature réglementaires.

Architecture MS SQL Server & Modèle de Données
Modèle Relationnel
Moteur SQL Server & Maintenance

L'application s'appuie sur le driver mssql / msnodesqlv8. Le modal d'administration (SqlModal.jsx) fournit les requêtes d'inspection et de migration DDL pour la gestion du schéma.

Sécurité & Tokens JWT

Gestion des sessions sécurisée via jetons JWT transmis dans l'en-tête HTTP Authorization: Bearer. Mots de passe chiffrés en base via le protocole bcryptjs.
